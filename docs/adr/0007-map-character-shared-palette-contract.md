# ADR-0007: マップタイルとキャラクターの共有palette契約

- 状態: Accepted
- 決定日: 2026-09-08

## 背景

地形一括コンパイルでは、選択した `final.png` の可視画素から実測したRGB集合を基準paletteとして表示・保存している。キャラクターを別のスプライトシートから生成すると、同じ作品内でも自動paletteの選択結果がずれる可能性がある。既存の地形palette仕様はキャラクターを対象外としていたため、その境界を拡張する。

## 決定

1. 地形側の `final.png` に含まれるアルファ非ゼロ画素のRGB集合を正本とする。デバッグ画像や元画像からpaletteを推測しない。
2. 正規化した色一覧と `palette-rgb-v1` のハッシュから `palette_id` を作り、terrain batchの `palette.json` をキャラクターGUIから検証付きで読み込めるようにする。
3. 地形一括変換ウィンドウで基準paletteを選ぶと、メインGUIのキャラクター単体・待機アニメーションにも同じRGB集合を固定paletteとして渡す。メインGUIでは色一覧、色数、IDを表示する。
4. 共有paletteの色数は1～64色とし、コンパイラへ渡すpalette予算は `max(4, 色数)` とする。paletteの色を水増しせず、入力にない色の追加生成もしない。
5. 共有paletteを解除した場合は既存の自動palette経路へ戻す。共有paletteを使った出力は `palette_id` の短縮値を出力ディレクトリ名に含め、同じ入力・設定の既存出力を上書きしない。

## 却下した案

- 複数スプライトシートの色を再学習して新しい「最適palette」を作る案は、地形側の正本RGBを変更するため採用しない。
- palette画像を逆解析して色を決める案は、透明画素や未使用色の意味が不明確になるため採用しない。
- キャラクターごとに近似した色役割を自動対応させる案は、色の意味を推測するため採用しない。固定paletteへの最近傍量子化に限定する。

## 影響

palette契約はGUI層から `pixel_tile_compiler.palette_contract` へ移し、既存のterrain向けimportは互換ラッパーで維持する。共有palette未設定時の出力名と変換動作は変更しない。共有paletteの実際の見た目の調和は、各素材の最終画像を目視確認する範囲とし、palette契約テストではRGB集合の一致を検証する。
