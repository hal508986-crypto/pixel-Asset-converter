# ADR-0010: 成分所属確認の大量診断表示とコマ単位ワークフローへの刷新

- 状態: Superseded（コマ単位ワークフローへ改訂）
- 決定日: 2026-09-09（初版決定・同日Superseded改訂）
- 関連: [成分分割仕様](../spec/animation_component_split_spec.md)

## 背景

成分分割は、元画像全体の `V = (alpha > 0)` を所有権の正本にする。そのため、微小なalpha>0成分を含む入力では、確認待ちの理由に大量の成分IDを含める可能性がある。実素材では数千成分（2,319成分）にのぼるため、同じID列をGUIの状態ラベルやCLI標準出力へそのまま展開すると可読性を損なう。

### 当初の決定とその破綻経緯

当初は以下の通り決定した:
1. 利用者向け理由には未割当成分IDの先頭12件と残数のみを表示する（要約表示）。
2. 全成分の所属指定を検証対象とし、「全成分が明示指定されるまでコンパイルを完了扱いにしない」。

しかし、この方針は**実素材の検証において致命的な破綻**を招いた:
- 表示を要約しても、内部的には2,319個すべての成分について所属確定を求めたため、GUI側で2,319個のコンボボックスが生成されUIが停止・画面外へ溢れた。
- 利用者の真の目的は「12コマの抽出」であり、不可視に近い数千個の微小粒（alpha=1〜2のチリ）を手動で分類することではない。
- 「全成分の明示確認」を義務付けたことで、実画像でのコンパイル完了に決して到達できない状態に陥った。

## 新しい決定（コマ単位ワークフローへの移行）

1. **「全成分明示確認」の撤回と内部完全性保証:**
   人による全成分の手動確認を義務付けず、画素の欠落・重複ゼロはCoreの数学的内部検査（V上のRGBA完全一致、未割当0、重複0）で保証する。
2. **各行本体候補の自動抽出と周辺画素の安定仮所属:**
   各行の検出マスク `D` から行・位置・規模・実画素間距離に基づき指定コマ数の本体候補を決定的・説明可能に作成し、周辺の微小成分・低アルファ画素を最近傍実画素距離変換で最も近い本体コマへ安定的に仮所属させる。同距離や弱い根拠でも決定的規則で仮配置し、未指定の大量発生で操作を停止させない。
3. **F1〜Fn抽出プレビュー主体のUI:**
   数千件のコンボボックスを撤去し、主画面に各コマ（F1〜Fn）の抽出プレビューを配置。疑わしい領域（境界近傍、遠隔残像等）をハイライト表示する。
4. **元絵上の領域選択によるまとめて修正:**
   元絵上で成分をクリックまたは矩形選択して、選択した成分の所属先Fnをまとめて変更できる方式とする。
5. **一括確定:**
   全コマを確認後、利用者が「一括確定」することでコンパイルを完了可能とする。

## 影響

- 利用者は2,319件の入力から解放され、12コマの抽出結果を直接確認し、問題箇所だけを直観的に修正してコンパイルを完了できる。
- CLIおよびCoreも同じ契約を利用し、仮所属抽出プレビューと疑わしい領域診断を出力してGUIと安全に受け渡しできる。

## 検証

- 実素材（1448×1086, 2,319成分）において手動入力なしで12コマの抽出プレビューが表示され、一括確定によりF1〜F12の最終PNGが出力できること。
- 抽出段階のRGBA完全一致、画素欠落0、重複0が内部検査で証明されること。
