# 地形バッチ変換・パレット比較・統一再コンパイル

## 0. 実装担当への前提

本書は既存コンパイラへの追加仕様。実装前に現行コード・AGENTS.md・関連スキルを確認する。

- G-1: 本書の対象範囲を守る。キャラクター変換の仕様変更を混ぜない。
- G-2: 受け入れ条件から失敗するテストを書き、最小実装、責務整理の順に進める。
- G-3: 新規依存は追加しない。必要になれば採用理由と仕様変更を先に記録する。
- G-4: 原画・既存出力・他作業の未コミット変更を保全する。コミット・公開は別指示。
- G-5: 条件や値を推測で埋めず、仕様変更と検証の限界を記録する。

UIは日本語、ファイルはUTF-8。設計上のファイル名は提案であり、既存責務に合わせた変更は可。

## 1. 概要と1動作デモシナリオ

複数の地形原画をまとめて変換し、結果と使用色を一覧で確認する。
気に入った一枚を基準に選び、チェックした画像をそのパレットで原画から再コンパイルする。
初回結果と統一後の結果を残し、同じ倍率で比較できる。

デモ: 草原と道の原画を複数追加 → 「まとめて変換」 → 一枚を選んで使用色を確認 → 「このパレットを基準にする」 → 対象にチェック → 「選択画像を基準パレットで再変換」 → 変換前後を比較。

## 2. ユーザー像と痛み

開発中のSRPGへ64×64pxの地形を取り込む制作者が対象。現在は外部バッチとdebug画像で個別の結果を確認している。
個別減色では同じ草でも色が揃わず、比較と再変換に手間がかかる。
本機能は色の候補を共通化する。光源、陰影の面積、描き込み密度、道幅、接続位置の差は解消しない。

## 4. 技術スタックと採用ゲート結果

既存Python、PySide6、Pillow、CompilerConfigを利用する。追加ライブラリ・モデル・フォント・ネットワークサービスは0。
新規依存の5問採用ゲートはN/A（新規採用なし）。既存依存のライセンスを本書で再監査したとは扱わない。

確認した既存接続点:

- `src/pixel_tile_compiler/gui/main_window.py`: 単画像変換、地形変換条件、パレット予算のUI。
- `src/pixel_tile_compiler/gui/input.py`: 現在は最初の対応画像を選ぶ補助処理。複数選択は追加が必要。
- `src/pixel_tile_compiler/gui/policy.py`: 地形の既定はnearest、24色、repeat無効。
- `src/pixel_tile_compiler/pixelizer/palette.py`: 固定色による減色が存在する。

- `CompilerConfig.palette_colors`: 固定色を渡す既存契約。予算の範囲は4〜64。

## 5. アーキテクチャ概略とモジュール境界

MainWindowは画面接続に限定する。以下の責務を適切な別モジュールへ分ける。

| 責務 | 担当すること | 担当しないこと |
|---|---|---|
| バッチモデル | 項目ID、原画、条件、結果履歴、状態 | Qtウィジェットの操作 |
| パレット情報 | finalから実使用色を取得、固定色検証、ID生成 | 画像の追加減色、色の自動補正 |
| 実行サービス | 凍結した要求を原画から順次コンパイル、保存 | 選択状態の読み取り、GUI操作 |
| 結果読み込み | 既存manifest・metadata・画像の検証 | 入力データ内の出力先への書き込み |
| Qtワーカー | サービス実行、進捗・結果・失敗の通知 | メインスレッド外でのウィジェット操作 |
| バッチ画面 | チェック、選択、プレビュー、操作可否 | コンパイラ処理の複製 |

### 5.1 画面と操作

既存の地形変換画面から「まとめて変換」を開く。既存テーマ・日本語の単画像操作は維持する。

```text
[画像を追加] [試作結果を読み込む] [選択項目を削除]
変換方法 [元絵を保持]  色数 [24]  repeat [無効]
一覧: 対象チェック / ファイル名 / 状態 / 使用色数 / パレットの色見本
詳細: 選択結果のプレビュー / 変換前・変換後 / 全色の色見本
      [このパレットを基準にする]
基準: ファイル名・結果ID・基準色数・全色の色見本 [基準を解除]
[まとめて変換] [選択画像を基準パレットで再変換] [中止]
進捗: 完了数 / 対象数、成功・失敗・中止の件数
```

- 行選択は詳細表示、チェックは処理対象。両者を分離する。
- 初回追加は全件チェック。未変換・成功・失敗・待機中・処理中・中止を文字で示す。
- プレビューは最近傍拡大。前後を同倍率で表示し、対象の結果IDを明示する。
- 「変換前」は今回の再変換開始時に選択されていた結果を指す。原画も別表示できる。
- 色見本はRGBまたはHEXをツールチップと選択可能な文字で確認できる。状態を色だけで示さない。
- 基準未選択または対象0件なら再変換は無効。理由を画面内に表示する。
- 固定色使用中は色数予算の編集を無効にし、「基準22色／この結果の使用18色」のように区別する。
- 処理中は基準・対象・条件の変更と項目削除を無効化する。閲覧は可能。
- 基準の行も対象に含めてよい。開始時の基準パレットを固定し、更新された結果を参照し直さない。
- キーボード操作、フォーカス表示、一覧スクロールを確保する。詳細はリサイズ可能とし、小さい画面で操作ボタンを隠さない。

### 5.2 パレットの正本

基準は選択した結果のfinal PNGに存在する、alphaが0でない画素のRGBの重複なし集合。RGB昇順で保存する。
既存debugの色見本は中間段階由来の場合があるため、基準抽出の入力にしない。
既存metadataの`transformation.palette_colors`はfinalと一致を確認して利用できる。一致しなければ警告し、finalの実測色を表示する。
再量子化する関数を実使用色の取得に流用しない。

予算24色でも実使用22色なら基準は22色。24色まで補充しない。再変換結果はその22色の部分集合でよく、全色使用は要求しない。
固定パレットのコンパイラ予算は`max(4, 基準色数)`とし、元の個別予算とは別に記録する。0色・65色以上の結果は基準にできない。
完全透明画像は色数0、基準選択無効。透明RGBを基準に混ぜず、alphaの既存契約を維持する。

### 5.3 再コンパイルの契約

原画ファイルを再読込し、選択した前回結果の寸法・方式・repeat等の有効条件を引き継ぎ、パレットだけを固定指定へ変更する。
縮小済みfinalを再入力しない。現在の画面の変更済み条件で暗黙に上書きしない。
各項目の完全な有効CompilerConfigを初回から保存する。旧結果で条件を復元できなければ不足項目を表示し、利用者が明示設定するまで再変換対象にできない。
原画SHA-256を開始直前に確認する。欠落・変更時はその項目を失敗にし、別画像へ自動置換しない。

実行要求は対象ID・原画情報・前回結果ID・条件・基準色を凍結したスナップショット。
単一ワーカーで一件ずつ処理する。全原画を同時にメモリへ保持しない。
「中止」は現在の一件の終了後に次の開始を止める。完了済み結果は保持し、未着手だけを中止にする。
一件の失敗で他の項目を止めない。終了・例外時もボタンとワーカーを正常に片付ける。

## 8. データとファイル配置

出力ルート内に新規のバッチ専用ディレクトリを作る。時刻だけに依存せずUUID等で衝突を防ぐ。

```text
Output/batches/<batch_id>/
  batch_manifest.json
  runs/<run_id>/
    run_manifest.json
    palette.json             # 固定パレット実行時のみ
    items/<item_id>/         # 既存コンパイラのfinal・metadata・debug
```

manifestの書込はUTF-8、一時ファイルからの置換で中途半端なJSONを防ぐ。結果は別runへ追記し、元runを上書きしない。
実行中も完了項目ごとに状態を保存する。強制終了後の自動再開は対象外だが、不完全runを成功扱いしない。

新形式の必須情報:

- `schema_version`: 1。
- バッチ・項目・実行・結果の一意ID。表示用ファイル名を識別子にしない。
- 原画のパス・SHA-256・寸法、完全な有効変換条件。
- 初回／固定パレットの方式、前回結果ID、出力パス・SHA-256、状態・エラー。
- 実使用色と実使用色数。色数予算と混同しない。
- 固定色実行では基準結果ID・基準画像hash・許可色一覧・パレットID。

パレットIDは、重複除去してRGB昇順に並べた色のRGB各1byteを連結し、先頭にASCII `palette-rgb-v1\n`を付けたbytesのSHA-256。パスやJSON整形に依存させない。
基準色一覧はrunにコピーし、後から基準ファイルが移動しても条件を説明できるようにする。

## 9. エラー設計の方針

行ごとに短い日本語の理由と次の操作を表示し、技術詳細は展開表示またはログへ保存する。

| 状況 | 表示・対応 |
|---|---|
| 原画が無い | 「原画が見つからないため再変換できません」。元の場所への復元を案内 |
| 原画hash不一致 | 「原画が前回から変更されています」。変更後の画像は新規項目として追加 |
| 条件不足 | 「前回の変換条件を確認できません」。不足条件の明示設定へ誘導 |
| 基準色数不適合 | 基準選択を無効化し、0色または上限超過を表示 |
| 書込・変換失敗 | 当該行を失敗にして詳細を保存。他の行は続行 |
| 中止 | 完了済みは成功を維持、未着手を中止とする |
