# 正面・2頭身MAP駒の画像生成テンプレート

作成日：2026-09-07。アリアの正面MAP駒v3を基にした再利用用の生成文。新しい画像の生成はこの文書の作成に含めていない。

## 用途と固定条件

- 実機サイズ：64×64pxの透過PNG。
- 1枚に1キャラクター、正面向きの待機姿。
- 約2頭身。頭頂から顎までと、顎から靴底までをおよそ同じ高さにする。
- 顔・肩・胸・腰・両足を正面へ。クォータービュー、斜め向き、俯瞰を使わない。
- 大きな色面と明快な輪郭を優先し、細かい刺繍・指輪などは省略する。
- 台座・背景・接地影・文字を付けない。

生成モデルへの64×64・色数・透過の指定は保証ではない。生成原画の後に寸法、アルファ、減色、配置の処理と検証を行う。手打ちのドット絵や、元画像の格子を厳密に復元した出力とは説明しない。

## 差し替える情報

設定資料から次を埋める。未設定の武器・紋章・宝石は補わない。

- `{{靴}}`

背景の透過に失敗した場合は後処理で解決する。服や肌に近い色を無条件で全削除しない。

## 出力後の工程と確認

1. 原画を保存し、背景が本当に透過しているか確認する。PNG形式だけでは透過の証明にならない。
2. 必要なら外側につながる背景を除去し、髪・衣装・リボン・足の欠損を確認する。
3. 可視bboxを切り出し、縦横比を保って54×54以内へ最近傍で縮小する。
4. アルファを二値化し、ディザなしで減色する。可視色と透明色の数え方を明記する。
5. 64×64キャンバスへ、水平中央・足元位置を揃えて配置する。出力単位で余白を指定する。
6. 寸法、アルファ値、可視色数、bbox、見切れを検証する。実寸と最近傍8倍の両方で、目・輪郭・装飾の読み取りを確認する。

今回のv3はImageMagickで最近傍縮小と最大24色への減色を行い、identifyの色数は21色（透明色を含む）だった。アプリが表示する可視RGB数と直接比較しないこと。

今回の配置コマンドは、54px高へ縮小した人物の下に4pxを追加し、その58px高の画像を64pxへ中央配置したため、結果の下余白は7pxとなる。今後はこの操作列をそのまま契約にせず、出力アンカーを明示する。
