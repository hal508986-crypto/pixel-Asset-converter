# ADR-0008: 戦闘アニメ行別分割の近接帯処理と共有palette既定値

- 状態: Accepted
- 決定日: 2026-09-08
- 関連: [行別分割仕様](../spec/battle_animation_row_split_spec.md)、[ADR-0006](0006-battle-animation-coordinate-and-detail-contract.md)、[ADR-0007](0007-map-character-shared-palette-contract.md)

## 背景

行別のalpha投影では、斬撃などの離れた大きなエフェクトが本体と数pxだけ離れていると、Y投影が一つの行を二つの可視帯として観測することがある。期待行数が設定されていても、任意の帯を結合すると、離れたエフェクトを推測で別行へ所属させる危険がある。

また、アニメーションの各frameを個別に減色すると、同じ動作中でもframeごとに量子化paletteが変わり、色ちらつきの原因になる。今回の依頼では、初回変換時に動作全体でpaletteを解決することを既定にする。

## 決定

1. 行別分割のY/X投影が期待帯数を超えた場合、隣接帯の隙間が `min_gutter_width_px + 1` 以下で、最小隙間が一意のときだけ、その二帯を結合する。これは近接した同一frameのエフェクトを取り込むための限定的な救済である。
2. 条件を満たさない余分な帯、期待数未満、同率最小の隙間は曖昧とみなし、明示 `row_alpha_gap` ではエラーにする。`hybrid` では失敗理由を記録して次候補へ進む。
3. 行別の境界は可視maskを8近傍で横切らない整数位置だけを候補にし、中央に近い順、同距離は小さい座標を採用する。安全な位置がなければ採用しない。
4. `CharacterAnimationConfig.shared_palette_enabled` は既定で有効にする。可視RGBを全frameから一度だけ抽出し、同じpaletteを各frameの減色へ渡す。明示的な無効化と固定palette指定は従来どおり許可する。

## 却下した案

- 期待行数に合わせて余分な帯を常に最近傍行へ割り当てる案は、離れたエフェクトの所属を推測するため採用しない。
- frameごとにpaletteを抽出し、結果の色集合だけを後から比較する案は、量子化時の色対応が揺れるため採用しない。
- 画像寸法・今回の素材に依存した固定境界や固定列幅は、他の入力へ一般化できないため採用しない。

## 影響

行別結果は可変幅の `source_box`、`row_bands`、`logical_origin`、`registration_translation` を診断JSONへ保存する。既存の固定・自動分割は従来の検出経路を維持し、hybridだけは自動→行別→固定の順で試行する。共有paletteの既定有効化により、新しいアニメーション出力ではframe間のpaletteが統一されるが、元画像の色差そのものを修正するものではない。

## 検証

近接帯、曖昧な余分帯、行ごとに異なる列境界、source_box全域分割、論理原点、hybridの試行履歴をpytestで確認する。実素材では指定された4×3画像を別出力先へ変換し、JSONの境界・frame数・共有palette・最終PNG名を実測する。
