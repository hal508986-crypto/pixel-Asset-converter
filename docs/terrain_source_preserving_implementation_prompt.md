## 実装内容

### 1. 地形の元絵保持経路

既存 `PixelTileCompiler` の `pixelization_mode="nearest"` を再利用してください。`_pixelize_source` はobject以外なら背景処理済み原画から直接出力サイズへ最近傍縮小し、`_clean_pixelized` はnearestの場合にクラスタ整理を省く実装です。まずこの経路の到達性と挙動を確認し、同じ処理を別実装しないでください。

地形では画像全体を64×64へ変換します。キャラクター用のbboxフィット、人物枠、足元余白、追加輪郭、自動背景除去、character detail簡略化を持ち込まないこと。原画のアルファを扱う既存の地形方針を維持してください。

元絵保持の基本比較は「原画から直接最近傍縮小→指定色数へ減色→出力」です。繰り返し最適化は独立した後処理として扱い、無効時に本経路へ平滑化・領域代表色への置換・微小クラスタ除去が混入しないことを確認してください。解析用の処理が残っていても、最終画素がその結果に依存しないことを区別して説明してください。

繰り返し最適化を有効にすると既存処理で形が変わり得ます。nearestという名前だけで形状完全保持を約束せず、実際に適用した後処理をmetadataへ記録してください。既存の単体反復機能とMAP契約付きコンパイルの分離を維持すること。

### 2. GUIから変換方法を選ぶ

地形用途に日本語の選択肢を追加してください。候補ラベルは次のとおりです。

- 「元絵を保持」: ピクセルアート風の原画の形と明暗を残す。
- 「領域を整理」: 細かな情報をまとめて地形を簡略化する既存方式。

「元絵を保持」を今回のGUI地形用途の初期選択にし、繰り返し最適化は初期状態を無効として比較を始められるようにしてください。既存ユーザー設定の永続化がある場合は保存済みの選択を勝手に上書きせず、初期値との扱いを明記してください。コア・CLI・シートコンパイル全体の既定を一括変更しないこと。

色数設定と繰り返し最適化の有効／無効は両方式で使用可能にしてください。方式切替後に古い結果を新方式の結果として表示しないよう、既存の結果無効化処理を利用してください。キャラクター用途では地形専用の選択肢を隠し、既存64px/128pxの挙動を維持してください。

GUIは共通コアの設定を作る責務に留め、画像処理を埋め込まないでください。CLI／コアでも同じ設定で再実行できるようにすること。

### 3. 比較出力と追跡性

変換方法を切り替えても結果が同じパスで失われないようにしてください。方式別の識別に加え、今回の比較は24色・繰り返し最適化OFF/ONを識別できる新規出力先へ保存します。既存 `terrain_64x64` の結果を移動・改名・上書きしないでください。

metadataには、入力ハッシュ、入力サイズ、出力サイズ、方式、色数予算、実際の色数、使用パレット、繰り返し最適化の適用有無を追跡できる情報を残してください。既存metadataにあるものは再利用します。

## 固定原画での検証

まず原画の存在とハッシュを確認し、不変コピーを新規実験ディレクトリに保存してください。原画がない場合は通常実装・合成テストを進め、実画像検証だけ未実施として報告すること。

同じ64×64出力について、以下を比較してください。

1. 原画から直接最近傍縮小のみ（色数無制限の参照）。
2. 元絵保持、24色、繰り返し最適化OFF。
3. 領域整理、24色、繰り返し最適化OFF。
4. 元絵保持、24色、繰り返し最適化ON。

2と3は共通の固定24色パレットによる比較も行ってください。単に両方を24色上限にするだけでは選ばれる色が異なるため、空間的な情報損失の比較とは分けます。パレットは同じ入力から抽出し、抽出元と方法を記録してください。GUIの通常設定と固定パレット比較の違いも明記すること。

実寸、最近傍整数拡大、3×3反復プレビューを出力してください。目視の確認点は、葉先の明部、根元の暗部、草のまとまり、単独の点状ノイズ、反復時の継ぎ目です。色数・アルファ・寸法の合格だけで「画風改善」と判定しないでください。

## テストと受け入れ条件

- 地形の「元絵を保持」がnearest経路へ届き、object用処理を適用しない。
- 非中央の特徴やキャンバス端の模様を勝手に中央寄せ・余白追加・切り抜きしない。
- 繰り返し最適化OFFの元絵保持経路が、領域代表色への置換で模様を失わない。
- 64×64、指定した色数予算、既存のアルファ方針を満たす。
- 方式切替、地形⇄キャラクター切替で設定と結果表示が混線しない。
- GUIとコアの同一設定が同じ画素結果になる。
- 既存region・単体反復・キャラクター64px/128px・MAP採用ゲートの関連回帰を確認する。
- 固定原画の比較成果物と再実行手順があり、原画・既存結果のハッシュが不変。

意味のある失敗テストを先に用意し、Red→Greenを確認してください。単に設定値を列挙するテストだけで完了にしないでください。

変更内容と理由、テスト結果、GUIで確認した操作、固定原画の比較先、どの識別点が残ったか／失われたか、未検証事項を報告し、docsへハンドオフを保存してください。今回の1入力の結果を他の素材全般へ一般化しないでください。
