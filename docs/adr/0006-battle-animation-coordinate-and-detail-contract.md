# ADR-0006: 戦闘アニメーションは共通座標・縮尺・色の契約でコンパイルする

- Date: 2026-09-08
- Status: Accepted for implementation direction（未実装。品質既定値は実測待ち）
- Scope: Characterの単体／戦闘アニメーション。MAPの論理セルは対象外
- Related: [仕様書](../spec/battle_animation_compiler_spec.md)、[実装プロンプト](../battle_animation_compiler_implementation_prompt.md)、[ADR-0004](0004-output-canvas-vs-tile-size.md)、[ADR-0005](0005-native-character-resolution-selection.md)、[旧待機仕様](../map_unit_idle_animation_trim_spec.md)

## 背景

生成原画などの「ピクセルアートらしい画像」を、ゲームで使える明瞭な画素と配置へ整えることを重視する。
戦闘アニメでは武器・マントの張り出しや跳躍があるため、個別bbox-fitと最下端の固定は身体の膨縮や移動消失を招く。
Compilerは既に縮小を担っており、縮尺と配置を動作単位で管理する責任を持たせるのが自然である。

2026-09-08のコードには長方形Canvas、Characterの4〜64色設定、待機用共通倍率が存在する。一方、待機配置はframeごとの可視bottomを揃え、減色は個別である。今回の判断はこれらの既存機構の延長であり、全機能の新設ではない。

## 決定

1. **Canvasとスタイルを独立させる。** 正方形に限定しない。256/512も原画から直接出力し、解析Canvasや64px完成画像から再拡大しない。36色以上はまず既存上限64色内で比較する。
2. **動作内で共通の等方倍率と座標変換を使う。** 個別のbbox変動を倍率や原点へ反映しない。ソース座標にある跳躍や突進を保持する。
3. **待機の足元固定と戦闘の移動保存を別モードにする。** 既存の無指定動作を維持する。戦闘用原点は最初から明示指定できるようにし、自動足認識を必須にしない。
4. **動作内fitと動作間縮尺を区別する。** 前者は全frameを収める。後者は既知倍率または利用者指定の基準長を再利用する。入力の画素密度が異なるときに同じ数値倍率だけで身体が揃うとは主張しない。
5. **固定倍率での見切れは明示的に解決する。** 必要Canvasを提示し、勝手な縮小や切り取りをしない。原点に対する左右上下の余裕で判定する。
6. **動作単位で共有paletteを解決する。** 色数は上限とし、透明RGBを除外。輪郭色も予算に含め、最終frame群の色の和集合を検証する。
7. **細部は面積だけで消さない。** 出力1pxの接続・輪郭・保護領域を評価する。縮小前の成分削除にも保護を適用する。失われた特徴の自動再描画は別問題として残す。
8. **余白と細部密度を分離する。** 同じ身体倍率でCanvasだけ大きくしても、細部整理を強めない。新方式の閾値を単純なCanvas面積比例で確定しない。

## 比較した選択肢

| 選択肢 | 判断と理由 |
|---|---|
| フレームごとに最大fit | 不採用。動作で身体の縮尺が変わる |
| 全動作を常にunion-fit | 動作内では採用。動作間の身体サイズ統一には不十分 |
| 全frameを最下端で接地 | 待機互換に限定。跳躍・足より下の武器では不適切 |
| 自動骨格・足推定を最初に導入 | 延期。誤推定と新規依存を避け、明示原点で成立させる |
| 原点と倍率を明示・保存 | 採用。調整負担はあるが結果を再現・説明できる |
| 解像度に比例して色数を固定増加 | 不採用。解像度と色数を独立比較する |
| 高コントラスト1pxを無条件に意味ある点とする | 不採用。ノイズもあり、接続や保護指定と合わせる |

## 帰結と制約

原点指定の操作が必要になる代わりに、Compilerが造形を理解する前から、縮小と配置の安定を提供できる。
共有paletteや共通倍率は、原画自体の顔・体格・色の不一致を修正する保証ではない。
最近傍縮小では連続移動が整数画素へ量子化される。丸めとサンプリング位相を固定するが、任意倍率で時間方向の揺れがゼロとは言わない。
巨大Canvas・多数frame・拡大プレビューの資源上限は実測する。新しい既定の色数やdetail閾値は比較結果から選ぶ。

ADR-0004のCanvas／MAPセル分離、ADR-0005のNative出力方針を継承する。旧待機仕様は待機互換モードに残す。新モードの座標と細部密度については本ADRと今回の仕様を優先し、過去の実験結果は書き換えない。

## 実装順と検証

P0：可変Canvas・明示原点・共通変換・移動保存 → P1：動作間再利用・共有色 → P2：細部保護・実素材比較。
武器伸長・跳躍・下へ伸びる装備・長方形・奇数寸法・異なる原画密度のfixtureで検証する。
色や画素の形式的整合性と、綺麗さ・採用可否の人間評価を分けて記録する。詳細な受け入れ条件と未決事項は仕様書7節・13節を正本とする。
